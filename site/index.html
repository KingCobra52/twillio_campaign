Siddarth Thota Personal Alerts

A private SMS reminder program operated by one individual, for one recipient. It is not a commercial service, and it is not open to public enrollment.

This program has exactly one recipient: Siddarth Thota, the operator. There is no signup form on this website. No one else can be added to the program from this site, and no one else currently receives messages from it.

What this program is

Siddarth Thota Personal Alerts sends short reminder text messages to a single mobile number belonging to the operator. The messages are personal reminders — appointments, deadlines, recurring chores, and similar notes the operator wants delivered to their phone.

Messages are sent through Twilio, a licensed communications provider. This website exists to publish the program's disclosures, privacy practices, and terms so they can be reviewed by the operator, by Twilio, and by mobile carriers.

What this program is not

  • It is not a marketing, promotional, or advertising program.
  • Mobile numbers and SMS consent data are not sold, rented, or shared with third parties or affiliates for marketing or promotional purposes.
  • It does not accept public signups, and it has no enrollment form, API, or mailing list.
  • It does not send messages on behalf of any other person, business, or organization.
  • It is not an emergency, medical, safety, or security service, and must not be relied on as one.
