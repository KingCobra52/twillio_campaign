Purpose of the messages

Siddarth Thota Personal Alerts sends short text-message reminders to the operator's own mobile number. Typical messages include appointment reminders, deadline reminders, and recurring task reminders that the recipient has asked to receive by SMS.

The program sends no marketing, advertising, or promotional content, and it sends no messages on behalf of any other individual, business, or organization.

How enrollment works

There is no signup form on this website, and no public enrollment of any kind. This site publishes disclosures only. It does not collect mobile numbers, and nothing on it can add a person to the program.

Enrollment is manual and covers a single recipient. The operator enrolls their own verified mobile number directly, outside of this website, before any message is sent. That manual step is the program's record of consent, and it is the only way a number enters the program.

Because the operator and the recipient are the same person, no third-party consent is collected, stored, or relied on. If the program is ever extended to a recipient other than the operator, express written consent will be captured from that person first, through a separate consent workflow, and this page will be updated to describe it before any message is sent.

Message frequency

Message frequency varies. Messages are sent only when a reminder the recipient has set becomes due, so the number of messages in a given week or month depends entirely on how many reminders are scheduled. There is no fixed send schedule, no recurring broadcast, and no guaranteed minimum or maximum number of messages.

Cost and carrier charges

The operator does not charge the recipient anything for this program. However, message and data rates may apply. Standard text-message and data charges from the recipient's mobile carrier are the recipient's responsibility, and they depend on the recipient's mobile plan. Questions about those charges should go to the recipient's mobile carrier.

STOP, START, and HELP

The program honors the standard SMS keywords. Keywords are not case sensitive.

  • STOP — Reply STOP to any message to stop all messages from this program. The program replies once to confirm, and then sends nothing further. Related keywords such as END, CANCEL, UNSUBSCRIBE, and QUIT are treated the same way.

    Siddarth Thota Personal Alerts: You have been unsubscribed and will receive no further messages. Reply START to resubscribe. Support: hellotheking52@gmail.com

  • START — After opting out, reply START to resume messages. Related keywords such as UNSTOP and YES are treated the same way.

    Siddarth Thota Personal Alerts: You are resubscribed to personal reminder alerts. Msg frequency varies. Msg&data rates may apply. Reply HELP for help, STOP to cancel.

  • HELP — Reply HELP to any message for support information. INFO is treated the same way.

    Siddarth Thota Personal Alerts: Personal reminder messages for one enrolled recipient. Support: hellotheking52@gmail.com. Msg frequency varies. Msg&data rates may apply. Reply STOP to cancel.

When a recipient first enrolls, or resubscribes after opting out, the program sends a single confirmation message:

Siddarth Thota Personal Alerts: You are now subscribed to personal reminder alerts. Msg frequency varies. Msg&data rates may apply. Reply HELP for help, STOP to cancel.

Opting out can also be requested by email at hellotheking52@gmail.com. Replying STOP is faster and takes effect immediately.
